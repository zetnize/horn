## Изменения проекта

Все типографические значения находятся в app/globals.css. Исправлены прежние предположения о шрифте заголовков, размеров, размерной сетки и описания товара. Для кнопок большая макетная строка совмещена с нулевым вертикальным padding, чтобы не увеличить кнопку вдвое. Минимальные интерактивные области и focus сохранены.

## Файлы шрифтов ещё нужны

Проверка свойств Figma подтверждает назначения, но не устанавливает шрифты в браузер сайта. В репозитории пока нет исходных файлов; на машине не обнаружены нужные начертания. Сейчас в CSS работают предусмотренные fallback. Равенство реально отрисованных начертаний с Figma пока не подтверждается.

Нужны четыре WOFF2 с кириллицей для next/font/local:

- Actay Regular — 400;
- Actay Wide Bold — 700;
- Monochrome Sans Medium — 500;
- Helvetica Neue Regular — 400.

Из макета не извлекались контуры букв, скриншоты не использовались вместо текста. Файлы со сторонних неофициальных каталогов не добавлялись.
