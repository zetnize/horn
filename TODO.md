- Все ≈ в design-tokens.md. Без фотографий и шрифтов точное совпадение невозможно.
- Цвета по фото: Судьба голубой; худи серый; Свобода чёрный/молочный; лонгслив молочный/чёрный. Подтвердить оттенки.
- Размеры из 1.txt: у первого товара нет L, хотя он есть на макете детальной страницы.
- Шесть сегментов первого слайдера — шесть кадров; пока серые плейсхолдеры. У остальных по одному.
- Заголовки/кнопки Actay Wide; обычный текст Actay; BASE DROP/цены Monochrome Sans; футер Helvetica Neue. Пока fallback.
- Форма говорит «1-5 дней», карточка «3-5 дней»: сохранены тексты ТЗ/макета, подтвердить.
- Размерные сетки низкого разрешения: нужны качественные оригиналы.
- Меню: КАТАЛОГ → /#catalog, ПРЕДЗАКАЗ → /cart, СПОСОБ СВЯЗИ → /#contacts. Подтвердить.
- Лист ожидания, ошибки и пустая корзина без макетов; минимальный вариант в общей стилистике.
- Загрузчик @tailwindcss/turbopack стартового шаблона отдавал устаревшую CSS после правок. Заменён на официальный @tailwindcss/postcss; экспериментальное отключение кэша убрано.
- Доступность отличается от миниатюрных контролов макета: область нажатия 44 px, явная обводка фокуса, ручное замыкание Tab в dialog.
- Ссылка Figma получена: https://www.figma.com/design/BgXJsA0lBpNQdPKMvs38Ui/northia?node-id=2702-295 . Коннектор отказал (нет требуемого доступа редактора), браузер получил HTTP 403. Данные Figma и исходные фото не извлечены.
- Для читаемости текста на белом/сером фоне muted/legal затемнён до ≈ #6b6b6b; это сознательное отличие от светлого футера макета. Белые подписи на временных серых фото требуют финальной проверки после подстановки оригиналов.
